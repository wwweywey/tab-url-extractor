Tab URL Extractor - Privacy Policy

Applies to Tab URL Extractor version 1.0.0

Tab URL Extractor helps you copy or export URLs from browser tabs. It works locally in the browser where it is installed.

Data access

When you open the toolbar popup, the extension reads the URLs, selection state, and tab order of accessible tabs in that browser window so you can choose which URLs to copy or download. When you select tab-bar right-click Copy URLs or Extract URLs, it reads the selected URLs in that window. Because of the browser's tabs permission, it can technically access more tab URLs than you choose, but the implemented features only use URLs as described here. Browser URLs may contain sensitive information.

Data use and temporary storage

Copy URLs writes chosen URLs to your system clipboard. Download TXT saves a local file containing chosen URLs. Tab-bar Extract URLs temporarily writes URLs to browser extension session storage to display an editable results page in a new tab in the same window; it removes the temporary entry when the results page reads it. The popup does not persist a tab history.

No transmission or tracking

The extension does not transmit URLs or browsing activity to the developer, publisher, or third parties. It contains no analytics, tracking, advertisements, accounts, or remote code and makes no network requests to provide its features.

Private windows

If you allow the extension in private windows, the popup reads only URLs from the private window that opened it. Extracting from the tab-bar menu opens a new results tab in the same private window, without automatically falling back to a regular window. Copied URLs may remain in the system clipboard and downloaded TXT files remain on the device outside the private session.

Retention and choices

The extension does not keep permanent URL histories. Temporary extraction records are removed upon reading or when browser session storage is cleared. Clipboard and downloaded files remain under your control. You can disable or uninstall the extension from the browser's extension settings.

Updates and questions

This policy will be updated if data handling changes. For inquiries, use the contact details provided by the publisher in the browser extension store listing.
